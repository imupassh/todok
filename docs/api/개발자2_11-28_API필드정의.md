> `reviews`는 `type`으로 글/음성 2종(명세서 2행)을 한 엔드포인트로 처리 → 명세서 14행을 모두 커버. 운영자 전용 자원 id는 내부 정수, 대상 콘텐츠는 `public_id(UUID)`.

### 주요 운영자 DTO
- **ReviewItem**: `id·targetType·targetId·queueType·createdAt` + (TEXT)`title·content` / (VOICE)`audioUrl·sttText·sourceText·filterResult`. STT는 대상 `stt_text` 조인.
- **ReportQueueItem**: `id·targetType·targetId·reasonCode·severity·reportCount·audioUrl·sttText·sourceText`.
- **Sanction**: `level(WITHDRAW/WARNING/UPLOAD_BLOCK)·reason·startsAt·endsAt·reportId`.
- **Metrics**: `weeklyConnections·reEngagementRate·cheeredReadingRate·letterDeliveryRate·reviewWaitMedianHours·reportRate`.

### 제재 자동 단계 (decision=ACTIONED)
누적 ACTIONED 횟수 → **1회 WITHDRAW(내림) · 2회 WARNING(경고) · 3회 UPLOAD_BLOCK(7일 올리기 제한)**. UPLOAD_BLOCK 중 업로드·편지 보내기 차단, 청취·받기 허용.

## 3. 서버 자동 작업 설계서 3건 (상세: `개발자2_11-28_서버자동작업설계.md`)

| 작업 | 트리거 | 핵심 로직 | 기능 |
| --- | --- | --- | --- |
| ① 편지 도착 처리 | 편지 승인 시(이벤트) | 전달+우체통 insert, **안읽음 5개 유지**(6번째 도착 시 가장 오래된 1개 소각), 5개 도달 소각 알림 1회, 도착 푸시 | L-01·L-06·L-07 |
| ② 열람 편지 24h 삭제 | 주기(SKIP LOCKED) | `READ && expires_at<=now && 북마크 아님` → EXPIRED. S3는 참조 없을 때만 정리 | L-06·L-10 |
| ③ 요청 마감·0통 삭제 | 주기(SKIP LOCKED) | 24h 경과: 검수중(마감 전 제출) 있으면 CLOSING 보류(L-04), 1통+ CLOSED, 0통 EXPIRED 소프트삭제·푸시없음(L-09), 7일 후 하드삭제 | L-03·L-09·L-04 |

공통: 멱등(상태+타임스탬프 조건), 동시성(FOR UPDATE SKIP LOCKED / 수신자 UNREAD 잠금), 푸시는 개발자 1 FCM 모듈 위임, S3 삭제는 참조 소멸 시에만.
